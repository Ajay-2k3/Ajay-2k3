## 01 — StockIQ

### AI Stock Prediction & Monitoring Platform

**MCA Final-Year Project**

A full-stack platform for monitoring Indian NSE/BSE stocks and providing AI-assisted price and **BUY / SELL / HOLD** predictions.

### What I built

- Developed the frontend using **React 18, TypeScript, Vite, and Tailwind CSS**.
- Built stock dashboards, candlestick visualization, watchlists, portfolio workflows, alerts, risk analysis, and prediction history.
- Developed backend services using **Node.js, Express, and TypeScript**.
- Integrated a separate **Python + FastAPI** machine-learning service.
- Used **PostgreSQL** for persistent application data.
- Used **Redis** within backend and application-data workflows.
- Implemented real-time updates using **Socket.IO / WebSockets**.
- Integrated market and news data using **Yahoo Finance / yfinance** and **NewsAPI**.
- Explored and used **LSTM, Transformer, Random Forest, XGBoost, and DQN** models across prediction workflows.

### Project-reported results

| Metric | Result |
|---|---:|
| 1-day ensemble prediction MAPE | **≈ 2.1%** |
| Trend classification accuracy | **≈ 78.4%** |
