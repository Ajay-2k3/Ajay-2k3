## Featured Projects

### StockIQ — AI Stock Prediction & Monitoring System

**MCA Final-Year Project** · [Repository](https://github.com/Ajay-2k3/stockiq-smart-flow)

Real-time Indian stock monitoring and prediction platform for NSE/BSE combining a full-stack web application with a dedicated Python ML service.

* Built a **React 18 + TypeScript** frontend with stock dashboards, candlestick visualization, watchlists, portfolios, alerts, risk analysis, and prediction history.
* Developed the application backend using **Node.js, Express, and TypeScript**, with **PostgreSQL** for persistent data and **Redis** for application data workflows.
* Integrated a **FastAPI + Python** ML service for stock price prediction and **BUY / SELL / HOLD** trend classification.
* Used **Socket.IO / WebSockets** for real-time application updates.
* Worked with market and news data through **Yahoo Finance / yfinance** and **NewsAPI**.
* Explored and used **LSTM, Transformer, Random Forest, XGBoost, and DQN** approaches across prediction workflows.
* **Project-reported results:** approximately **2.1% MAPE** for the 1-day ensemble price prediction and approximately **78.4% trend classification accuracy**.

**Stack:** React 18 · TypeScript · Vite · Tailwind CSS · Node.js · Express · FastAPI · Python · PostgreSQL · Redis · Socket.IO
